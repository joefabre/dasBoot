# Employment Search Resources

A collection of professional documents, templates, and resources for job searching in technology and cybersecurity roles. This repository contains carefully crafted materials for various positions and companies.

## Contents

### Cover Letters
- General templates
- Role-specific letters
- Company-tailored versions

### Resumes
- Role-specific resumes
- Format variations
- Skills matrices

### Interview Preparation
- Technical Q&A sheets
- Interview preparation guides
- Role-specific interview materials

### Career Transition
- Transition summaries
- Skill mapping documents
- Industry-specific materials

## Organization

The repository is organized by:
- Role type (e.g., SOC Operator, Security Analyst)
- Company/Organization
- Document type (Resume, Cover Letter, etc.)

## Private Information

Note: This repository contains templates and examples. Personal information and sensitive details have been removed or anonymized.

## Usage

- Use these materials as templates
- Customize for specific roles
- Update with relevant experience
- Maintain consistent formatting
