docker build

Builds an image from a Dockerfile.

How docker build Works

Purpose: Creates a Docker image from the instructions in a Dockerfile and a specified context (directory or URL).

Function: Docker reads the Dockerfile and executes the commands sequentially, creating a new image layer for each instruction.

Impact: Produces a new docker image locally that can be run as a container or pushed to a repository.

Performance: Depends on the complexity and number of layers in the Dockerfile. Caching can significantly speed up rebuilds.

Common Use Cases

  • Packaging applications and dependencies into an image
  • Building custom software stacks for development and production
  • Creating images for CI/CD pipelines
  • Building base images for various application runtimes
Basic Image Build
docker build -t myapp:latest .
Build with No Cache
docker build --no-cache -t myapp:no-cache .

docker run

Runs a command in a new container.

How docker run Works

Purpose: Creates and starts a new container from a Docker image.

Function: Docker creates a container based on the specified image, allocates a filesystem, and executes the specified command within that container.

Impact: Starts a new container instance, which runs until the specified command terminates.

Performance: Fast startup due to layered file system. Resource usage depends on container configuration.

Common Use Cases

  • Running isolated applications or microservices
  • Testing and debugging software in a controlled environment
  • Executing batch jobs and automation scripts
  • Starting development environments with all dependencies
Run with Interactive Shell
docker run -it ubuntu bash
Run Detached with Port Mapping
docker run -d -p 80:80 nginx
