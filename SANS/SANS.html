SANS Applied Cybersecurity Certificate Overview

The SANS Applied Cybersecurity Certificate (ACS) is designed to validate foundational cybersecurity knowledge and practical skills. It covers essential security concepts, frameworks, and best practices.

Program Objectives:

  • Understand fundamental cybersecurity principles
  • Apply security frameworks and standards
  • Implement security controls and countermeasures
  • Analyze security risks and vulnerabilities
  • Respond to security incidents effectively

Linux Command Line Security

  • netstat -tulpn - Show active network connections and listening ports
  • ps aux | grep [process] - List running processes and search for specific ones
  • ss -tulpn - Modern replacement for netstat (socket statistics)
  • lsof -i - List open files and network connections
  • find / -perm -4000 2>/dev/null - Find SUID files (potential privilege escalation)
  • grep -r "pattern" /var/log/ - Search log files for specific patterns
  • tail -f /var/log/auth.log - Monitor authentication logs in real-time
  • chmod 600 file - Set secure file permissions (owner read/write only)
  • chown user:group file - Change file ownership
  • iptables -L - List current firewall rules
  • whoami && id - Show current user and groups
  • last -n 10 - Show last 10 login sessions
  • history | grep "command" - Search command history
  • tcpdump -i eth0 port 80 - Capture network traffic on specific port
  • md5sum file.txt - Generate file hash for integrity checking

Quick Reference Guide

Common Port Numbers

21 (FTP), 22 (SSH), 23 (Telnet), 25 (SMTP), 53 (DNS), 80 (HTTP), 110 (POP3), 143 (IMAP), 443 (HTTPS), 993 (IMAPS), 995 (POP3S)

Risk Calculation

Risk = Threat × Vulnerability × Impact

Risk levels: Low (1-3), Medium (4-6), High (7-9), Critical (10)

Incident Response Steps

  1. Preparation - Policies, procedures, tools
  2. Identification - Detect and analyze events
  3. Containment - Short-term and long-term
  4. Eradication - Remove threats and vulnerabilities
  5. Recovery - Restore systems and operations
  6. Lessons Learned - Post-incident review

Access Control Models

  • DAC - Discretionary Access Control
  • MAC - Mandatory Access Control
  • RBAC - Role-Based Access Control
  • ABAC - Attribute-Based Access Control

Cryptography Key Points

  • AES - Advanced Encryption Standard (symmetric)
  • RSA - Rivest-Shamir-Adleman (asymmetric)
  • SHA-256 - Secure Hash Algorithm
  • Key lengths: AES (128, 192, 256 bits), RSA (2048+ bits recommended)

Study Tips for Assessment

  • Focus on understanding concepts rather than memorizing
  • Practice with real-world scenarios and case studies
  • Review current threat landscape and emerging technologies
  • Understand the relationship between different security domains
  • Know when to apply specific frameworks and controls
  • Stay updated with latest security advisories and CVEs
